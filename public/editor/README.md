# BEEN 화면 편집기

배포된 앱 주소 뒤에 `editor/`를 붙여 엽니다. 예: `https://toquno-sayrin.github.io/BEEN-app/editor/`.

- 실제 메인 화면을 같은 출처의 iframe으로 불러옵니다. 로고, 상단 버튼, 지도 영역, 하단 메뉴와 각 메뉴 항목을 편집합니다.
- 드래그 이동, 8방향 크기 조절, X/Y/너비/높이 입력, Shift 다중 선택, 정렬, 숨김/복원, 잠금, 실행 취소/다시 실행을 지원합니다.
- 텍스트, 링크 버튼, 이미지, 도형을 추가하고 복제할 수 있습니다. 기본 앱 버튼의 복제나 새 기능 연결은 코드 작업이 필요합니다. 지도 안의 장소 및 마커는 앱의 기록 기능으로 관리합니다.
- `미리보기`에서는 지도를 조작하고 앱 버튼을 사용할 수 있습니다. 다른 화면으로 이동한 후 편집으로 돌아오면 메인 화면을 다시 불러옵니다.
- 격자 맞춤은 기본적으로 꺼져 있습니다. 켠 상태에서 Alt를 누르면 일시적으로 자유 이동합니다. 방향키는 1px, Shift+방향키는 10px 이동합니다.
- 위치 값은 현재 화면의 좌상단 기준입니다. 기본 요소는 원래 반응형 배치를 기준으로 이동량을 저장합니다. 작은 화면에서는 메인 화면 폭에 비례해 이동량·지정 크기를 줄입니다. 390px/480px/768px 화면 미리보기를 제공합니다.
- 메뉴 항목은 원래 메뉴 계층을 유지합니다. 앞뒤 순서도 해당 계층 안에서 적용되며, 메뉴 전체를 다른 요소 앞으로 옮기려면 `하단 메뉴 전체`를 선택합니다.

## 저장과 배포

초안은 `been:ui-layout-draft:v1`, 저장한 메인 화면 설정은 `been:ui-layout:v1`에 보관됩니다. 원래 장소/사진 데이터 키는 변경하지 않습니다. 저장한 설정은 같은 브라우저의 메인 화면에 적용되며, 다른 방문자에게 자동 게시되지 않습니다.

JSON 내보내기/불러오기로 백업하거나 다른 브라우저로 옮길 수 있습니다. 공개 기본값 변경이 필요하면 내보낸 설정을 개발 작업에 전달해야 합니다. GitHub 인증 정보나 토큰은 편집기에서 요구하거나 보관하지 않습니다.

이미지는 PNG/JPG/WebP/GIF 2MB 이하, 추가 요소는 60개까지입니다. 잘못된 설정 파일은 현재 편집 내용에 적용하지 않습니다. 저장 공간이 부족하면 내보내기를 사용하세요. 기본 배치 복원 후 저장하면 개인 배치 변경을 해제할 수 있습니다.

## 구현과 검증

`model.js`는 설정 검증과 순수 상태 변경, `runtime.js`는 웹 앱에만 배치를 적용합니다. Expo Go에서는 `LayoutRuntime.tsx`의 빈 컴포넌트를 사용합니다. 기본 설정에는 스타일 재정의가 없으며, UI 편집 도구는 앱의 화면 구조를 변경하지 않습니다.

`node --test tests/layoutModel.test.cjs`로 설정 모델을 검증합니다. `npx expo export --platform web --output-dir dist-editor-check` 후 `node tests/layout-browser.cjs`로 Chrome 헤드리스에서 실제 앱 편집 동작을 검증합니다. `CHROME_PATH`로 Chrome 실행 경로를 지정할 수 있습니다.
