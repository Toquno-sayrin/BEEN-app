# 메인 화면·프로토타입 변경 요약

## 제품 방향
- 핵심 문구: **내가 다녀온 곳들이, 나만의 세계가 된다.**
- 장소에 사진 기록을 남기고, 사진 속 대상을 미니어처로 표현해 지도를 채우는 방향으로 구체화했다.
- 미니어처 편집은 회전·크기·색감부터 시작한다. 모양 자체를 바꾸는 편집은 후속 논의로 남겼다.

## 화면과 동작
- 상단 기존 로고, 중앙 내 세계 지도, 하단 **탐색·추가·더보기·설정**으로 구성했다.
- 메인 검색창은 제거하고 **추가**를 누르면 장소·주소 검색이 열리게 했다.
- 탐색은 계정·피드 검색, 더보기는 추천 맵·피드용 예시 화면이다.
- 캐릭터 표시 여부 비교와 방향키·지도 클릭 이동을 추가했다. 건물 충돌 판정은 없다.
- 노트북·야광봉·검사 키트 SVG 미니어처를 배치하고, 클릭하면 원본 사진 카드 → 자세히 보기 → 편집으로 연결했다.
- 추가 흐름: 장소 입력 → 예시 위치 핀 선택 → 예시 사진 또는 파일 선택 → 대상 선택 → 미니어처 편집 → 지도에 놓기.

## 앱 디자인 변경
- 브랜드 로고·앱 아이콘을 정리하고 UI에 파랑·초록 색상을 반영했다.
- 반투명 글래스 표면, 그림자 높이 차이, 하단 내비게이션과 지도 정보 표시를 조정했다.
