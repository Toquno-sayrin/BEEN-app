# 내 세계 앱 구현

## 구현한 흐름
- 앱 시작 화면을 `WorldScreen`으로 연결하고 하단 메뉴를 탐색·추가·더보기·설정으로 변경했다.
- 네이버 장소 검색 → 위치 확인 → 사진 선택 → 예시 미니어처 선택·회전·크기·색상 편집 → 기기에 저장.
- 실제 네이버 지도에 방문 좌표별 번호·미니어처 마커를 표시한다. 선택하면 사진 카드, 상세, 수정·삭제로 이어진다.
- 모형 보기에서는 도식화한 세계와 탭으로 움직이는 캐릭터를 제공한다. 이 배치는 실제 지형이 아니다.
- 방문 기록들을 선택한 순서대로 묶어 코스를 생성한다. 코스 선택 시 해당 기록만 표시하고 연결선을 그린다. 실제 지도 자동 확대는 줌 14까지 제한한다.
- 코스 제목·장소·주소·메모·네이버 링크를 시스템 공유로 전달한다. 기존 코스 상세 화면도 내 코스에서 접근 가능하다.
- 같은 장소의 재방문은 서로 다른 방문 기록으로 보관한다. 기록 삭제 시 코스 참조도 정리한다.
- AsyncStorage에 기록·코스·편집값을 저장하며 모바일 사진은 앱 문서 폴더로 복사한다. 웹은 이미지 데이터를 함께 저장하고 용량 초과 시 오류를 표시한다.

## 주요 변경 파일
- `App.tsx`, `src/types.ts`: 앱 진입·화면 연결·데이터 타입.
- `src/screens/WorldScreen.tsx`: 지도·검색·사진·편집·코스·공유 흐름.
- `src/worldModel.ts`: 저장 데이터 검증·기록 삭제 처리.
- `src/components/Miniature.tsx`, `miniatureMarker.ts`: 예시 모형과 지도 마커.
- `src/components/CourseMap.tsx`, `CourseMap.native.tsx`, `naverMapDocument.ts`: 웹·네이티브 지도 마커, 확대 제한.
- `src/components/BottomNav.tsx`, `src/screens/HomeScreen.tsx`: 하단 메뉴와 탐색·추천 샘플 피드.
- `package.json`, `package-lock.json`: Expo 호환 image-picker, file-system, react-native-svg 추가.
- `tests/worldModel.test.cjs`, `tests/world-browser.cjs`: 데이터 및 브라우저 통합 검증.

## 검증
- `node node_modules/typescript/bin/tsc --noEmit`: 통과.
- `node --test tests/worldModel.test.cjs`: 5개 통과.
- Expo export 웹·Android·iOS: 통과. Windows Hermes 실행 권한을 허용한 상태에서 확인.
- 390×844 브라우저: 빈 세계, 저장 복원, 코스 필터, 편집 저장, 삭제 후 코스 정리, 검색 응답 fixture → 위치 선택 → 실제 로컬 이미지 선택 → 저장까지 통과.
- 재현: `npx.cmd expo export --platform all --output-dir dist-world-check` 후 `node tests/world-browser.cjs`. 로컬 Chrome 필요, 다른 설치 경로는 `CHROME_PATH`로 지정. 테스트 프로필·스크린샷은 `artifacts`에 저장.

## 남은 범위
- Expo Go 실기기 실행과 실제 네이버 검색·지도 인증의 종단 간 확인은 미완료. 네이버 검색 서버의 허용 Origin 정책에 따라 로컬 웹 검색이 제한될 수 있다.
- 미니어처는 SVG 예시이며 실제 사진 대상 자동 추출·3D 생성이 아니다.
- 탐색·더보기는 기존 샘플 데이터이며 계정 서버·추천 알고리즘 미연결.
- 공유는 텍스트 전달이며 상대방이 동일한 인터랙티브 코스를 여는 공유 링크는 미구현.
- 모형 보기 캐릭터는 탭 이동을 제공한다. 브라우저 시안의 방향키 조작은 앱에 아직 이식하지 않았다.
- 공개 GitHub Pages의 `/prototype/`은 기존 HTML 시안이다. 이번 앱 변경은 아직 배포하지 않았다.
